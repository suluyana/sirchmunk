Sirchmunk 用户指南

欢迎使用 Sirchmunk 企业智能搜索系统

快速入门

1 安装

使用 pip 安装 Sirchmunk：

pip install sirchmunk
2 初始化配置

运行初始化命令创建配置文件：

sirchmunk init
3 配置 LLM

编辑 ~/.sirchmunk/.env 文件，设置您的 LLM API 密钥

命令行使用

命令 说明 示例
search 执行搜索 sirchmunk search "认证流程"
serve 启动 API 服务 sirchmunk serve --port 8584
cache stats 查看缓存状态 sirchmunk cache stats

常见问题

Q: 如何清除缓存？
A: 运行 sirchmunk cache clear
Q: 支持哪些文件格式？
A: PDF、DOCX、PPTX、TXT、MD、代码文件等 50+ 种格式
Q: 如何配置 OSS？
A: 运行 sirchmunk oss init 进行配置
