Getting Started

Sirchmunk is an AI-powered search engine designed for enterprise environments.

Note: This documentation covers version 1.0.0 and above.

Quick Start Guide

  1. Install the package: pip install sirchmunk
  2. Initialize: sirchmunk init
  3. Configure your LLM API key
  4. Start searching: sirchmunk search "your query"

Warning: Always ensure your API keys are stored securely and never committed to version control.

Supported File Formats

  • Documents: PDF, DOCX, PPTX, XLSX
  • Text: TXT, MD, RTF
  • Code: PY, JS, TS, JAVA, GO, RS
  • Web: HTML, XML, JSON
  • Images: PNG, JPG (OCR support)
